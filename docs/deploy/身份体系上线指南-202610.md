## 0. 前置（部署前一次性完成，取码后执行）

1. **备份**：`mysqldump -u root -p sysu_bme > backup_$(date +%Y%m%d_%H%M).sql`——回滚底气。
2. **.env 三密钥**（生产必配，缺省行为见 .env_example D1 节）：
   - `AUTH_LEGACY_TOKEN_DEADLINE`：**显式固定**为部署日 +14 天（ISO 日期时间）。不设则每次重启顺延并告警。
   - `MFA_ENC_SECRET`：`python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`。
   - `MEDIA_SIGN_SECRET`（建议独立）；`CHALLENGE_HMAC_SECRET`（可选，默认由 JWT_SECRET 派生）。
3. **staging 预演**（D1.5 #6）：在 staging 跑 `bash bme-migrate-run.sh`（62-66 幂等可重跑）+
   下方全部回填 dry-run，核对零异常后再上生产。
4. **CORS/同源**：若开 cookie 模式（AUTH_REFRESH_COOKIE_ENABLED，本批默认关），需 nginx 同源路径
   或 CORS credentials 二选一验证——不开则无需动。

## 2. 开闸序列（每级独立可回拨；逐级观察再下一步）

| 序 | 开关 | 动作 | 回拨语义 |
|---|---|---|---|
| 1 | （无开关） | 部署即生效：会话真相源/撤权/审计脱敏/验证码 purpose/媒体短签 v2/密码门槛 8 位 | 属安全修复不回拨；D1.5 演练已验证 |
| 2 | `IDENTITY_ENFORCEMENT_MODE=shadow`（默认） | 人员规则只记账本（`identity.enforcement.shadow` 事件）观测 | 改 `off` 即停评估 |
| 3 | 管理端 `/system/identity/schools` | **配 ≥2 名核验审核人**（reviewer_user_ids，运营就绪标志转绿）+ 核对个人域清单 | 随时可改，版本自增 |
| 4 | `IDENTITY_UI_ENABLED=true` + `IDENTITY_VERIFICATION_ENABLED=true` | 身份中心入口开放（个人中心「身份与账号」），用户可发起核验 | 拨回 false=停新申请，已提交仍可查 |
| 5 | `ACCOUNT_LINK_APPLY_ENABLED=true` | 账号认领开放（建议核验通道稳定数日后再开） | 拨回 false=停新案例 |
| 6 | `AUTH_REFRESH_COOKIE_ENABLED=true`（独立决策，可暂不开） | refresh 迁 HttpOnly cookie；**拨回 false 即零发版回退**（已实测） | 前端无需发版 |
| 7 | `IDENTITY_ENFORCEMENT_MODE=enforce`（**不在本批**） | 待 shadow 观测数据稳定+宽限名单明确后（规格 13.3 强制阶段） | 改回 shadow |

发布广播：`python scripts/announce_release.py`（全站系统通知 + /changelog v3.4 条目）。

## 4. 回退路径

- **代码级**：回滚到上一发布 commit（新表新列对旧代码无感——只加不改）。数据不回滚。
- **开关级**：上表每级独立回拨；cookie 模式回拨零发版；enforcement 永不放开 merged/banned 会话。
- **归并误操作**：applied 案例不做自助拆分——按规格 10.3 走补偿（备份+operation 清单+人工三方比对），
  误关联立即撤会话（bump 已自动完成）。
- **灾难恢复**：整库备份恢复需暂停写入并明确恢复时间点（规格 14 章）。

## 5. 已知边界（随批携带，非阻塞）
