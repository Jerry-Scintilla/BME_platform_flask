# docs/deploy — 生产环境部署指导

本目录是**生产环境部署/升级指导文件的唯一归处**（2026-09-15 起）。服务器上只有本仓库，部署文档跟着代码走，不再放外部归档仓。

## 现有文件

| 文件 | 内容 |
|---|---|
| `服务端迁移指南.md` | 总指南：历次升级的增量节 + 通用步骤（备份/依赖/迁移/构建/重启/验证/回滚），从外部归档仓迁入 |
| `静态资源迁移指南-202609.md` | 2026-09 静态资源体系增量：头像/导生照/勋章图/轮播入 storage、课程封面链路、migrate_32 |

## 约定

1. **每次涉及生产变更的升级，增量指导写成本目录下的 md 文件**，命名 `主题-年月.md`（如 `静态资源迁移指南-202609.md`）；同时在 `服务端迁移指南.md` 顶部加一节增量提示指向它；
2. 涉及部署顺序硬约束（如「先迁移再上代码」）必须在增量文件开头显著标注；
3. 迁移脚本放 `scripts/migrate/`（编号递增、幂等可重跑），增量文件里写明执行顺序与验证命令；
4. 回滚方案必写：代码（git reset）+ 数据库（备份恢复）+ 数据目录（备份恢复）三件套。
