## 3. 数据迁移（按序，幂等）

```bash
python scripts/migrate/migrate_32_static_media.py
```

脚本做九件事（逐项打印 `[+]`/`[=]`/`[WARN]`）：
1. `medal` 表加 `image` 列；
2. 建 `banner` 表（首页轮播）；
3. seed `banner_management` 权限并授权全部 super_admin；
4. 存量头像搬入 storage（默认转 WebP 256×256，坏图回退原样字节），`user.avatar_url` 改存 `/media/...`；
5. 存量导生名片照搬入 storage，`camp_mentor_profile.photo` 改存 `/media/...`；
6. 勋章图上传并回填 `medal.image`（源文件在 `scripts/migrate/assets/medals/`，中文名勋章走别名映射，
   无图的回填 Default 占位——管理页可后换）；
7. banner 空表时 seed 3 帧（现有轮播内容，图已压缩为 WebP；`is_camp_frame=0` 跟随 09-14 撤动态帧决定）；
8. `DROP TABLE IF EXISTS home_cover`（对应蓝图是零调用死代码，已删；data/homeCover 本就为空）；
9. `{DATA_ROOT}/avatars`、`mentor_photos` 重命名为 `*.migrated-202609`（不删，人工验证后清理）。

> **无 `scripts/migrate/assets/` 的报错提示**：assets 由 dev 机 `scripts/optimize_assets.py` 产出并随代码提交。
> 若分支里没有该目录，说明代码没拉对；勋章/轮播两步会明确提示并跳过（其余步骤正常）。

## 5. nginx 可选优化：`/media` 本地缓存（非必须）

后端已回 `Cache-Control: immutable`，浏览器侧零重复请求；nginx 再加一层磁盘缓存可省跨机带宽
（同机部署收益小，可不加）：

```nginx
# http 块
proxy_cache_path /var/cache/nginx/media levels=1:2 keys_zone=media_cache:10m max_size=500m inactive=30d;
# server 块现有 /api 转发的同级
location /api/media/ {
    proxy_pass http://127.0.0.1:5000/media/;      # 端口与现有 proxy_pass 对齐
    proxy_cache media_cache;
    proxy_cache_valid 200 30d;
    add_header X-Cache-Status $upstream_cache_status;
}
```
