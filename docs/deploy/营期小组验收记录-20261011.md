## 本轮修复

- 两端培训小组接入 DewUI 卡片、按钮、实底弹窗、选择器、标签和加载态；表格局部适配主题，窄屏不再由管理工作台内容撑宽。
- 课程展示名称；弹窗重开清理上次输入；改名不清空原课程范围；切营忽略过期请求。旧大一营保留原导生提示。
- MySQL 核心职责时间改为微秒，避免刚授予的职责因秒级舍入暂时不可见；迁移 76 同步组会任务布置时间精度。
- 映射预览使用数据库持久化时间，避免虚假摘要冲突；修复 MySQL 共享非阻塞锁语法。
- 保留旧小组接口与物理数据；补齐兼容退役文档的 Git 跟踪例外。
