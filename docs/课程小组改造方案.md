# 课程小组改造方案（含 CRUD API）

## 1. 目标

1. 保证学生必须已选修课程，才能加入该课程小组。
2. 支持一门课有多个老师小组。
3. 保证同一学生在同一课程下只能加入一个小组。
4. 提供完整的小组 CRUD API，并包含“用户加入/退出小组”。

## 2. 当前模型检查结论

## 2.1 已满足

1. `course_group` 已有 `UNIQUE(course_id, teacher_id)`，可支持同课多老师组，并限制同老师同课程重复建组。
2. `course_group_member` 增加了 `course_id`。
3. `course_group_member` 已有 `UNIQUE(student_id, course_id)`，可阻止同课多组。
4. `course_group_member` 已有 `(student_id, course_id) -> user_course(user_id, course_id)` 复合外键，可保证“先选课再入组”。

## 2.2 需修正/补充

1. 建议在 `course_group` 增加（或确认迁移层存在）`UNIQUE(id, course_id)`，用于稳定支撑 `(group_id, course_id)` 复合外键引用。
2. `add_member` 只按 `(group_id, student_id)` 查重，未显式判断“同课程其他组”；目前依赖数据库唯一约束兜底，冲突时会抛数据库异常，建议转成业务化 `409`。
3. `create_or_update_group` 是“创建/更新混合接口 + 清空重建成员”，不利于标准 CRUD 和审计，建议拆分为 `POST` 创建与 `PUT` 更新。
4. 缺少用户自助“加入/退出小组”接口，当前仅老师加/移成员。

## 3. 数据结构建议（最终版）

## 3.1 `course_group`

字段（核心）：

1. `id` PK
2. `name`
3. `course_id` FK -> `course.id`
4. `teacher_id` FK -> `user.id`
5. `student_limit`
6. `status` (`active|paused|completed`)
7. `created_at` / `updated_at`

约束：

1. `UNIQUE(course_id, teacher_id)`，同老师同课程仅一个组。
2. `UNIQUE(id, course_id)`，供成员表复合外键引用。

## 3.2 `course_group_member`

字段（核心）：

1. `id` PK
2. `group_id`
3. `course_id`
4. `student_id`
5. `joined_at`

约束：

1. `UNIQUE(student_id, course_id)`，同一学生在同一课程仅一个组。
2. `FOREIGN KEY(group_id, course_id) -> course_group(id, course_id)`，组与课程强一致。
3. `FOREIGN KEY(student_id, course_id) -> user_course(user_id, course_id)`，必须有选课记录才可入组。

说明：

1. 若还需“仅允许在读状态可入组”，`user_course.status='active'` 需在 API 层校验（外键无法表达条件）。

## 4. API 设计（CRUD + 用户加入/退出）

统一前缀：`/course-groups`

认证：全部接口需 JWT。

角色约定：

1. 老师：可管理自己创建的小组。
2. 学生：可查询公开列表、查看详情、加入/退出自己所在组。
3. 管理员：可拥有跨组管理权限（可选）。

---

## 4.1 创建小组（C）

`POST /course-groups`

用途：老师在某课程下创建自己的小组。

请求体：

```json
{
  "name": "Python强化1组",
  "course_id": 12,
  "student_limit": 30,
  "status": "active"
}
```

校验：

1. `course_id` 存在。
2. `(course_id, teacher_id)` 不重复。
3. `student_limit > 0`。

成功：`201`

```json
{
  "code": 201,
  "message": "created",
  "data": {
    "id": 101,
    "name": "Python强化1组",
    "course_id": 12,
    "teacher_id": 7,
    "student_limit": 30,
    "status": "active"
  }
}
```

## 4.4 更新小组（U）

`PUT /course-groups/{group_id}`

用途：更新小组基础信息（不含成员批量重建）。

请求体：

```json
{
  "name": "Python强化A组",
  "student_limit": 35,
  "status": "active"
}
```

校验：

1. 仅组老师或管理员可更新。
2. `student_limit >= 当前成员数`。
3. `status` 在允许枚举内。

成功：`200`

---

## 4.5 删除小组（D）

`DELETE /course-groups/{group_id}`

用途：删除小组及成员关系。

校验：

1. 仅组老师或管理员可删除。

成功：`200`

---

## 4.6 老师添加成员

`POST /course-groups/{group_id}/members`

请求体：

```json
{
  "student_ids": [1001, 1002, 1003]
}
```

校验：

1. 仅组老师或管理员可操作。
2. 学生必须存在有效选课记录（`user_course` 里有 `(user_id, course_id)`）。
3. 学生未在该课程其他组中。
4. 不超过 `student_limit`。

成功：`200`

```json
{
  "code": 200,
  "added": [1001, 1002],
  "skipped_not_enrolled": [1003],
  "skipped_already_in_other_group": []
}
```

---

## 4.7 老师移除成员

`DELETE /course-groups/{group_id}/members/{student_id}`

校验：

1. 仅组老师或管理员可操作。
2. 目标学生当前确实在该组。

成功：`200`

---

## 4.8 用户加入小组（自助）

`POST /course-groups/{group_id}/join`

用途：当前登录学生加入指定小组。

校验顺序建议：

1. 当前用户是学生身份。
2. 小组存在且状态为 `active`。
3. 当前用户已选修该课程（`user_course` 存在且 `status='active'`）。
4. 当前用户未加入该课程其他小组（查 `course_group_member` 按 `student_id + course_id`）。
5. 小组未满员。

成功：`200`

```json
{
  "code": 200,
  "message": "joined",
  "data": {
    "group_id": 101,
    "course_id": 12,
    "student_id": 1001
  }
}
```

---

## 4.9 用户退出小组（自助）

`POST /course-groups/{group_id}/leave`

用途：当前登录学生退出指定小组。

校验：

1. 当前用户在该组内。

成功：`200`

```json
{
  "code": 200,
  "message": "left"
}
```

可选替代：

1. `DELETE /course-groups/{group_id}/members/me`（REST 风格更强）。

## 5. 错误码约定

1. `400` 参数错误。
2. `401` 未认证。
3. `403` 无权限。
4. `404` 资源不存在。
5. `409` 业务冲突（重复建组、同课多组冲突等）。
6. `422` 业务校验失败（未选课、课程状态不允许加入等）。

## 6. 关键校验伪代码

```python
def join_group(current_user_id: int, group_id: int):
    group = CourseGroup.query.get(group_id)
    if not group or group.status != "active":
        return 404_or_422

    enrollment = UserCourseModel.query.filter_by(
        user_id=current_user_id,
        course_id=group.course_id,
        status=UserCourseModel.STATUS_ACTIVE
    ).first()
    if not enrollment:
        return 422

    existing = CourseGroupMember.query.filter_by(
        student_id=current_user_id,
        course_id=group.course_id
    ).first()
    if existing:
        return 409

    if count_members(group.id) >= group.student_limit:
        return 422

    db.session.add(CourseGroupMember(
        group_id=group.id,
        course_id=group.course_id,
        student_id=current_user_id
    ))
    db.session.commit()
    return 200
```

## 7. 验收清单

1. 未选课学生无法加入小组。
2. 同一学生在同课程尝试加入第二个组时返回 `409`。
3. 同课程可创建不同老师的小组。
4. 同老师同课程重复创建失败。
5. 用户可自助加入和退出自己的小组。
6. 老师可增删自己组内成员。
