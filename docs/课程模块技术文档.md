# 课程模块技术文档

> 版本: 1.0
> 最后更新: 2026-03-03

---

## 1. 数据结构概述

课程采用三级层级结构：

```
课程 (Course)
  └── 章节 (Chapter)
        └── 课时 (Lesson)
```

---

## 2. 数据模型

### 2.1 课程 (Course)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Integer | 是 | 主键，自增 |
| title | String(100) | 是 | 课程标题 |
| introduction | Text | 是 | 课程介绍 |
| chapters | Integer | 是 | 章节数量（建议废弃，可动态计算） |
| cover | String(100) | 否 | 封面图片路径 |
| url | String(100) | 否 | 课程资料链接 |
| tags | String(100) | 否 | 标签（逗号分隔） |
| publish_time | DateTime | 是 | 发布时间，默认当前时间 |
| class_hour | Integer | 否 | 学时 |
| difficulty | Integer | 否 | 难度等级（1-5） |
| other_tags | String(100) | 否 | 其他标签（逗号分隔） |
| creator_id | Integer | 否 | 课程创建者ID |

---

### 2.2 章节 (Chapter)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Integer | 是 | 主键 |
| course_id | Integer | 是 | 关联课程ID |
| name | Text | 是 | 章节名称 |
| url | String(100) | 否 | 章节链接 |
| order | Integer | 是 | 排序字段，数值越小越靠前 |
| priority | Integer | 是 | 级别：0=章(Chapter)，1=节(Section) |

**注意**：
- `priority=0` 表示"章"（如：第1章 Python基础）
- `priority=1` 表示"节"（如：第1节 变量和数据类型）
- 同一课程下，`order` 值越小，显示越靠前

---

### 2.3 课时 (Lesson)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Integer | 是 | 主键 |
| chapter_id | Integer | 是 | 关联章节ID |
| course_id | Integer | 是 | 关联课程ID |
| title | String(200) | 是 | 课时标题 |
| type | String(20) | 是 | 课时类型 |
| content | Text | 否 | 课时内容（图文字内容或外链URL） |
| duration | Integer | 否 | 时长（分钟） |
| order | Integer | 是 | 排序字段 |
| is_preview | Boolean | 否 | 是否可免费预览 |
| resource_url | String(200) | 否 | 资源URL（视频/附件） |
| create_time | DateTime | 是 | 创建时间 |

**课时类型 (type)**：

| 值 | 说明 | 适用场景 |
|---|------|----------|
| video | 视频 | 视频教学 |
| text | 图文 | 文字教程 |
| link | 外链 | 跳转外部链接 |
| quiz | 测验 | 在线测验 |
| homework | 作业 | 作业提交 |

## 3. API 接口

### 3.1 课程管理

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | /course/public | 发布课程 | course_management |
| POST | /course/edit | 编辑课程 | course_management |
| GET | /course/list | 获取课程列表 | 公开 |
| GET | /course/search | 搜索课程 | 公开 |
| POST | /course/course_delete | 删除课程 | admin |

### 3.2 章节管理

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | /course/chapter_public | 创建/更新章节 | admin |
| GET | /course/chapter_list | 获取章节列表 | 公开 |

### 3.3 课时管理

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | /course/lesson/add | 添加课时 | 课程创建者或admin |
| POST | /course/lesson/edit | 编辑课时 | 课程创建者或admin |
| POST | /course/lesson/delete | 删除课时 | 课程创建者或admin |
| GET | /course/lesson/list | 获取课程下所有课时 | 公开 |
| GET | /course/lesson/detail | 获取课时详情 | 公开 |

## 4. 接口详细说明

### 4.1 发布课程

```
POST /course/public
Headers: Authorization: Bearer <token>
Body:
{
    "Course_title": "Python编程入门",
    "Course_Introduction": "零基础入门课程",
    "Course_Chapters": 10,
    "Course_Class_Hour": 20,
    "Course_Difficulty": 1,
    "Course_Tags": "Python,编程"
}
```

### 4.2 创建章节

```
POST /course/chapter_public
Headers: Authorization: Bearer <token>
Body:
{
    "Course_Id": 1,
    "Chapter_Name": [
        {"name": "第1章 Python基础", "order": 1, "priority": 0},
        {"name": "第1节 变量", "order": 2, "priority": 1},
        {"name": "第2章 条件判断", "order": 3, "priority": 0}
    ]
}
```

### 4.3 添加课时

```
POST /course/lesson/add
Headers: Authorization: Bearer <token>
Body:
{
    "Course_Id": 1,
    "Chapter_Id": 2,
    "Lesson_Title": "什么是变量",
    "Lesson_Type": "video",
    "Lesson_Content": "本节课介绍变量概念...",
    "Lesson_Duration": 15,
    "Lesson_Order": 1,
    "Is_Preview": true,
    "Resource_Url": "https://example.com/video.mp4"
}
```

### 4.4 获取课程下所有课时

```
GET /course/lesson/list?Course_Id=1
```

**响应示例**：
```json
{
  "code": 200,
  "message": "查询成功",
  "data": [
    {
      "chapter_id": 1,
      "chapter_name": "第1章 Python基础",

      "chapter_priority": 0,
      "lessons": [
        {
          "id": 1,
          "chapter_id": 2,
          "course_id": 1,
          "title": "什么是变量",
          "type": "video",
          "content": "本节课介绍变量概念...",
          "duration": 15,
```

## 5. 权限说明

### 5.1 权限类型

| 权限名称 | 说明 |
|----------|------|
| course_management | 课程管理权限 |
| user_management | 用户管理权限 |
| system_management | 系统管理权限 |

### 5.2 权限检查规则

- **课程创建者**：可管理自己创建的课程（添加/编辑/删除课时）
- **管理员 (user_mode='admin')**：可管理所有课程
- **普通用户**：只能查看课程内容

## 6. 前端开发注意事项

### 6.1 课程列表展示

1. 调用 `GET /course/list` 获取课程列表
2. 每个课程卡片显示：标题、介绍、章节数、难度、学时

### 6.2 课程详情页

1. 调用 `GET /course/search?Course_Id=1` 获取课程基本信息
2. 调用 `GET /course/lesson/list?Course_Id=1` 获取课时树状结构

### 6.3 课时播放页

1. 根据 `lesson.type` 渲染不同组件：
   - `video`: 视频播放器
   - `text`: 图文内容渲染（支持Markdown）
   - `link`: 外部链接跳转
   - `quiz`: 测验组件
   - `homework`: 作业提交组件

### 6.4 课时树状结构

```javascript
// 渲染示例
data.forEach(chapter => {
  if (chapter.chapter_priority === 0) {
    // 渲染章
    console.log(`📁 ${chapter.chapter_name}`);
  } else {
    // 渲染节
    console.log(`📄 ${chapter.chapter_name}`);
  }

  // 渲染课时
  chapter.lessons.forEach(lesson => {
    const icon = {
      'video': '📹',
      'text': '📝',
      'link': '🔗',
      'quiz': '❓',
      'homework': '📋'
    }[lesson.type];
    console.log(`  ${icon} ${lesson.title} (${lesson.duration}分钟)`);
  });
});
```
